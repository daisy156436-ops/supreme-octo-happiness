# 印刷用PDF

アプリの「⑤印刷」と同じものを、最初の設定（謎解き脱出は17チーム・32分・縦割り活動モード、陣取りクイズは16チーム・サンプル問題）でPDFにしたものです。A4たて・ふちなしで作っています（プリンターの設定で「用紙に合わせる」にしても大丈夫です）。

チームの数や名前、時間などを変えたときは、アプリの「⑤印刷」から印刷してください（このPDFは `node tests/export-pdf.js` で作り直せます）。
