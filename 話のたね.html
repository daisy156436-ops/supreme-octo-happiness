    読み込んだチャット

    ここにあるものすべてから、好きそうなテーマを読み取ります。

    • このアプリでの会話 自動で使います
    • Claude Code のセッション Claude Code に頼んだ作業の題名・日付・結果のメモを読みます（やりとりの中身は読みません）。はじめて押すと、読んでよいかの確認が出ます。
    • claude.ai のチャット ページから直接は読めないため、書き出したファイルを使います。
      1. claude.ai の［設定］→［プライバシー］で、データの書き出し（エクスポート）を押す
      2. メールで届くリンクから zip ファイルをダウンロードする
      3. 下の「ファイルや文章を取り込む」で、その zip を選んで「読み込む準備」を押す（展開しなくて大丈夫です）

    ファイルや文章を取り込む

    claude.ai の書き出し（zip または conversations.json）、ChatGPT の書き出し、LINE のトーク履歴（.txt）、コピーした文章などを読み込めます。会話が何百件あっても、全件の題名と書き出しから好きなテーマを読み取り、最近のものは中身まで読んで覚え書きにします。元の文章は保存しません。
