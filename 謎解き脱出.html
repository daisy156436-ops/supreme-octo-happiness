謎解き脱出ゲーム「体育館からの脱出」

どんなゲーム？

「体育館にとじこめられた！」というお話で、6人くらい（縦割りなら各学年2人ずつ）のチームが協力して謎を解きます。とびらは2つあります。

  • 第1のとびら：謎1〜6の答えの ○ の文字をならべると、あいことば。先生に見せると、第2ステージの紙がもらえます
  • 第2のとびら：少しむずかしい謎7〜9（謎9は、かけらを持ち寄る全員の協力の謎）の答えの 青い○ の文字で、最後のあいことば。先生に見せたら「脱出成功」
  • 🗝️ 裏ミッション：脱出したチームだけがもらえる、ひみつの暗号。これまでの謎の答えを使って解くと「真・脱出」

早く脱出したチームが上位です。脱出できなかったチームも、第1のとびらまでの早さで順位がつきます。早いチームにも最後まで考える謎があり、ゆっくりのチームも第1のとびらで達成感を味わえるようにしてあります。

  • 人数：縦割りなら6人（各学年2人ずつ）×17チームくらい（2〜20チーム）
  • 時間：50分（お話3分・チーム結成5分・ルールとれんしゅう2分・謎解き32分・解説と最後のとびら4分・表彰とふりかえり4分）
  • 用意：プロジェクターかテレビ＋このファイルを開いたパソコン、⑤で印刷した「謎の紙」（1チーム3ページ）・「第2ステージの紙」（1チーム2ページ）・「裏ミッションの紙」（1枚で2チーム分）・「チームシート」・「役割カード」、先生用の「台本と進行表」「答え合わせカード」、えんぴつと下じき。あれば「予告ポスター」「写真用パネル」
  • ⑤印刷の「台本と進行表」に、当日のセリフ・時刻・先生の役割分担・準備チェックリスト・会場の図がまとまっています。まずはこれを読んでください
  • タブレット：なくてもできます。あれば 謎解きカード.html を開くと、答えがその場で正解かわかり、第2ステージもタブレットで続けられます

時間の目安（50分）

0〜3分チームごとに座る。④本番の「お話」を映す
3〜8分チーム結成タイム（自己紹介・チーム名・役割）。チームシート・役割カード・謎の紙を配る（スタートまで裏返し）
8〜10分ルール説明 → れんしゅうの謎（予告ポスターの謎。答えの ○ の文字を集めるしくみを、1年生が答えて確かめる）
10〜42分謎解き32分。6分たつと、3分ごとにヒントがスクリーンに出る（第2ステージのヒントは24分から）。14分と25分に「伝令タイム」
42〜46分解説。まず答えの一覧、時間があれば1問ずつ → 裏ミッションの答え → 全員で声をそろえて開ける「最後のとびら」
46〜50分表彰（3位→2位→1位）・特別賞・ふりかえり

早いチームは15分ほどで第1のとびら、25分ほどで脱出し、のこり時間で裏ミッション。ゆっくりのチームも、ヒントと伝令タイムで第1のとびらまでは行ける、くらいの難しさです。

先生の進め方

  1. ②でチームの数・制限時間を決め、⑤で生徒にわたすもの（謎の紙・第2ステージの紙・裏ミッションの紙・チームシート・役割カード）と先生用（台本と進行表・答え合わせカード）を印刷します（③で答えを確認）
  2. ④「はじめる」→ お話（スペースキーで1行ずつ出る）→ チーム結成タイム → ルール → れんしゅうの謎 →「スタート！」でタイマーが動きます
  3. 第1のあいことばを持ってきたチームは、答えを確かめて、画面右のそのチームを押し、第2ステージの紙をわたします（伝令カードにスタンプ）
  4. 第2のあいことばを持ってきたら、もう一度押します（脱出タイムと順位が出ます）。裏ミッションの紙をわたします
  5. 裏ミッションの答え（真のあいことば）を持ってきたら、3回目を押します（👑真・脱出）
  6. 時間になるか全チームが脱出したら、解説 → 最後のとびら（全員で）→ 表彰 → 特別賞 → ふりかえり

押しまちがえたら「記録を取り消す」を押してから、そのチームを押します。スペースキー（か右下のボタン）で次へ進みます。途中でページを閉じても、開き直すと続きからできます。

縦割り活動として行うとき

②設定の「縦割り活動モード」を入れると（はじめから入っています）、次のしくみが加わります。

  • 学年ごとの担当：謎に「1年生から」「2年生から」「3年生から」のマークがつきます。まずその学年の人が考え、わからなければみんなで考えます。第1ステージはどの学年も2つずつ、第2ステージは1年生が謎7、3年生が謎8を担当。1年生の担当は、とっつきやすい謎（えもじ・しりとり・時間割）です
  • 全学年の協力の謎（謎9「3つのかけら」）：かけらを切りはなして、1年生（道順）・2年生（読む場所）・3年生（地図）が1枚ずつ持ちます。かけらは見せ合わずに、口で伝え合わないと解けません。学年をこえて話す場面を、しかけとして作っています
  • 役割：3年生＝リーダー（答えは言わずに、ヒントで下級生を導く）、2年生＝記録係（答えを集める）、1年生＝伝令（あいことばを先生に伝えに行く・伝令タイムの主役）。⑤の「役割カード」を1人1枚わたすと、やることがはっきりします
  • チーム結成タイム（5分）：自己紹介・チーム名・役割決め。タイマーつきの画面を映します
  • ふりかえり：表彰のあとに、MVP・上級生から下級生へ・下級生から上級生への一言。⑤で印刷する「チームシート」に書けます

チーム分けは、6人（各学年2人ずつ）がおすすめです。7人以上になると、謎を見られない人が出やすくなります。表彰とは別に、先生が見ていて「チームワーク賞」を伝えるのもおすすめです。

盛り上げるしかけ

  • ⚡ 伝令タイム（14分・25分）：スクリーンに「伝令タイム！」。各チームの1年生だけがスクリーンの前に集まり、15秒だけ出る「ひみつ情報」をおぼえて、チームにもどって伝えます（メモ禁止）。1年生が主役になる時間です
  • 🗝️ 裏ミッション：脱出したチームへの、ひみつの暗号。これまでの謎の答えを使います。早いチームも最後まで考えられます。解けたチームは「👑真・脱出」。答えは解説の最後に、みんなに発表します
  • みんなの目標：「全チーム 第1のとびら突破」。スクリーンにゲージが出ます。全チームそろうと「達成！」
  • のこり5分・1分の知らせ、最後の10秒は大きなカウントダウン
  • 🎖️ 特別賞：表彰のあとに「第1のとびら一番乗り」「真・脱出」「あきらめない賞」（表彰台の外で、最後まで粘って脱出したチーム）「チームワーク賞」（先生から発表）
  • 📸 写真用パネル：⑤で印刷。「脱出成功！」「真・脱出！」「あと一歩…！」を持って記念写真
  • 🆘 SOSカード：謎の紙の3枚目の下を切りとって使う、チームで1回だけのヒント券。見回りの先生にわたして、チーム名を元気に言うとヒントがもらえます（リアル脱出ゲームのヒント券やスタッフへの声かけと同じしくみ）。使うタイミングをチームで相談するので、リーダーの出番にもなります
  • 🪪 役割カード：⑤で印刷。3年生に「リーダー」（答えは言わずに導くことば集）、2年生に「記録係」（答えを集める表）、1年生に「伝令」（とびら突破スタンプ欄）。全員に、はっきりした出番ができます
  • 🚪 最後のとびら：解説の最後に、脱出できなかったチームもふくめた全員で声をそろえて合言葉を言うと、とびらが開き、「とびらを作った先輩たち」からの手紙が出ます。縦割り活動のしめくくりに
  • 🏅 証明書：本番のあとに⑤で印刷すると、チームごとにタイムと順位の入った「脱出証明書」（脱出できなかったチームは「挑戦証明書」）になります。後日わたすと、縦割りのチームの思い出が手元に残ります

伝令タイム・SOSカード・裏ミッションは、②設定で切れます。

ルール（生徒への説明）

  1. 謎1〜6を、チームで協力して解く（手分けしてもOK）
  2. 答えの ○ の文字を、謎の番号の順にならべると、第1のとびらのあいことば。3枚目の紙を先生に見せる
  3. 第2ステージの紙の謎7〜9を解き、青い○ の文字で最後のあいことば。先生に見せたら脱出成功。謎9は、かけらを1人1枚ずつ持ち、見せずに口で伝え合う
  4. ヒントは時間がたつとスクリーンに出る。「伝令タイム」には、各チーム1人（1年生）がスクリーンの前へ。困ったら「SOSカード」（チームで1回）
  5. 脱出したチームには、裏ミッションの紙。解けたら「真・脱出」
  6. ほかのチームに答えを教えない。答えは大きな声で言わない

タブレットを使うとき

  • 謎解きカード.html をチームのタブレットに配ります（ネットはいりません）。答えは暗号にしてあるので、ファイルを開いても答えは見えません
  • チームの番号を選び、先生の「スタート！」で画面のスタートを押します
  • 謎の答えを入れると、その場で正解かどうか出ます。第1のとびらを開けると「第1のとびら突破」の画面が出るので、先生に見せます。そのあと第2ステージに進めます。脱出すると、裏ミッションもタブレットでできます
  • 紙の謎も一緒に配ると、チームで手分けしやすくなります
  • このファイル（謎解き脱出.html）は生徒に配らないでください。答えが入っています

うまくいくコツ

  • 第2ステージの紙と裏ミッションの紙は、先生の手元にチーム数そろえておき、すぐわたせるようにします
  • むずかしそうなら②で制限時間をのばすか、ヒントを早めてください（本番中も「ヒントを今出す」「＋1分」が使えます）
  • 解説は、はじめに出る「答えの一覧」だけでもOK（「🗝️ 真のとびらへ」「🚪 最後のとびらへ」でとべます）。時間があれば「どの謎が一番むずかしかった？」と聞くと盛り上がります
  • 先生が2人以上いれば、司会・パソコン・答え合わせ（「答え合わせカード」を持つ）・見回りに分かれると、第1のとびらの答え合わせが混みません
  • 体育館の床で書くので、下じきかバインダーがあると書きやすいです。謎9のかけらを切るので、はさみを1チーム1本
  • 学校のパソコンでこのファイルを開けないときは、⑤印刷で「PDFとして保存」したPDFか、別に用意した「印刷用PDF」を使って印刷します（⑤印刷の下の説明）
  • 先生だけで一度リハーサルをしておくと安心です（④本番「はじめる」→ スペースキーで最後まで → ⑥保存「本番の記録を消す」）。設定に迷ったら②の「おすすめ設定」
  • 家のパソコンで準備して学校のパソコンで本番をするときは、⑥保存でファイルに書き出して運びます。本番のあとも書き出しておくと、記録が残ります
  • あいことばは「あきらめない」と「えがお」、裏ミッションは「みらいもなかま（未来も仲間）」。解説の最後にこのメッセージを見せて、ふりかえりにつなげてください

おたのしみ

その時間になると、スクリーンに「伝令タイム！」が出ます。各チームの1人（縦割りなら1年生）だけがスクリーンの前に集まり、15秒だけ出る「ひみつ情報」をおぼえて、チームにもどって伝えます（メモ禁止）。1回目は第1ステージ、2回目は第2ステージの情報です。全部で40秒ほど。

謎の紙の3枚目の下に、切りとって使う「SOSカード」が印刷されます。見回りの先生にわたして、チーム名を元気に言うと、好きな謎のヒントを1つもらえます。使うかどうかは、リーダーを中心にチームで相談して決めます。

脱出したチームに「裏ミッションの紙」をわたします。これまでの謎の答えを使う暗号で、解けたら「真・脱出」。早いチームも最後まで楽しめます。答えは解説の最後にみんなに発表します。

ファイルに保存・読み込み

チーム・設定・本番の記録は、このパソコンのブラウザに自動で保存されています。別のパソコンで本番をするときや、記録を残しておきたいときは、ファイルに書き出します。

家のパソコンで設定して、学校のパソコンで本番をするときは、「書き出す」→ USBメモリなどで運ぶ →「読み込む」。本番のあとに書き出しておくと、記録（タイム・順位）が残ります。
