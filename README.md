# 縦割り活動の謎解きゲーム「体育館からの脱出」使い方

中学1〜3年の縦割り活動（100人・50分）向けの謎解き脱出ゲームです。プロジェクターにつないだパソコン1台と、印刷した紙で遊べます。インターネットはいりません。

## 1. ファイルと置き場所

| ファイル | だれが | 何に使う |
|---|---|---|
| 謎解き脱出.html | 先生 | プロジェクターにつないだパソコンで開く。設定・本番の画面・印刷・保存。**答えが入っているので、生徒に配らない** |
| 謎解きカード.html | 生徒（使わなくてもよい） | タブレットで開くと、答え合わせがその場でできる。答えは暗号にしてあるので見えない |
| 印刷用PDF/ | 先生 | 印刷物の一式。アプリを開けないパソコン（校務用など）でも印刷できる。まず「はじめに読む（印刷のしかた）.pdf」を見る |
| 陣取りクイズ.html・回答カード.html | 先生・生徒 | 別のゲーム（クイズに答えて地図の陣地を取り合う）。使い方は 8 を見る |
| tests/ | — | 自動検査のプログラム（先生は使わない） |

- 最新版はこのページ（GitHubの表紙）にあります。まとめてダウンロード：[zip](https://github.com/daisy156436-ops/supreme-octo-happiness/archive/refs/heads/claude/hopeful-euler-0x2mth.zip)
- 開き方：ダウンロードしたファイルをダブルクリックすると、ブラウザ（Edge・Chrome など）で開きます。設定や本番の記録は、そのパソコンのブラウザに自動で保存されます。
- 画面の「版 2026-10-24」が、そのファイルの日付です。古い日付のものは使わないでください。

## 2. 当日の流れ（50分）

| 時刻 | 画面 | 先生がすること |
|---|---|---|
| 0〜3分 | お話 | ④本番「はじめる」。スペースキーで1行ずつ出るので、台本を読む |
| 3〜8分 | チーム結成タイム（5分） | 謎の紙（裏返し）・チームシート・役割カード・えんぴつを配る |
| 8〜10分 | ルール → れんしゅうの謎 | ルールを説明。れんしゅうの謎は1年生が答える |
| 10分 | スタート！ | 「3、2、1、スタート！」と同時にスペースキー |
| 10〜42分 | 謎解き（32分） | ヒントは6分後から3分ごとに自動で出る。14分と25分に伝令タイム（自動）。答え合わせの先生は、あいことばを確かめてチームのボタンを押す |
| 42〜46分 | 解説 → 最後のとびら | 答えの一覧 → 1問ずつ → 真のとびら → 全員で声をそろえて最後のとびらを開ける |
| 46〜48分 | 結果発表・特別賞 | 3位 → 2位 → 1位 → 特別賞 |
| 48〜50分 | ふりかえり（2分） | チームシートに書く → 終わりのことば |

くわしいセリフと時刻は、⑤印刷の「台本と進行表」（印刷用PDF の 00_台本と進行表.pdf）にあります。

## 3. 準備

謎解き脱出.html を開くと、①遊び方の上に「はじめての先生へ：3ステップ」と「準備チェックリスト」があります。チェックを入れながら進めると迷いません（チェックはそのパソコンに保存されます）。

### 2週間前から

- チーム分け：各学年2人ずつの6人で1チーム（100人なら17チーム）。チームの番号を名簿に書いておく
- 先生の役割分担：司会、パソコン（司会と兼ねてもよい）、答え合わせ1〜2人、見回り
- あれば：予告ポスター（印刷用PDF の 09）を教室や廊下にはる

### 1週間前から前日まで

1. 謎解き脱出.html の **②設定**：チームの数とチーム名を入れる。制限時間は「ふつう（32分）」のままでよい（1年生が多くて心配なら「やさしめ」）
2. **③謎と答え** で、謎と答えに目を通す
3. 印刷：印刷用PDF の「はじめに読む（印刷のしかた）.pdf」のとおりに印刷する（チーム名を変えたときは、アプリを開けるパソコンで ⑤印刷 →「印刷する」→ プリンターを「PDFとして保存」にしてPDFを作り、USBメモリで運ぶ）
4. 切る：裏ミッションの紙（半分に）、役割カード（6枚に）、答え合わせカード（4枚に）
5. 用意するもの：えんぴつ・消しゴム（1チーム2〜3本）、下じきかバインダー、はさみ（1チーム1本）、スタンプかサインペン（答え合わせの机）
6. 「台本と進行表」を先生全員で読む。チームワーク賞をだれが決めるか決めておく
7. 先生だけでリハーサル：④本番「はじめる」→ スペースキーで最後まで通す → ⑥保存「本番の記録を消す」
8. タブレットを使うなら、謎解きカード.html をチームのタブレットに入れておく（インターネットはいらない）

### 当日・始まる前

- プロジェクターとスピーカーをつなぐ → ④本番の「1. 音のテスト」→「2. 全画面にする」→「3. はじめる」の順に押す
- チームは番号順に座る。スクリーンの前は空けておく（伝令タイムで1年生が集まる）
- 答え合わせの机はスクリーンの横。第2ステージの紙・裏ミッションの紙は、チームの番号順に重ねて机の上に

## 4. 本番の操作（謎解き脱出.html の ④本番）

- 進む：**スペースキー**（または右下の大きいボタン）。お話は1行ずつ出る
- 操作に迷ったら：本番の画面の右上「？ 操作」（キーボードの ? でも）で、操作のメモが出る
- チームのボタン（画面の右）：あいことばが正しければ **1回目＝第1のとびら、2回目＝脱出、3回目＝真・脱出（裏ミッション）**。押しまちがえたら「記録を取り消す」→ そのチーム
- 謎解き中に使えるボタン：一時停止、＋1分、ヒントを今出す、ここで終わる
- 伝令タイム（14分・25分）は自動で始まる。「すぐに情報を出す」「伝令タイムを終わる」で早送りできる
- 解説：時間がないときは、答えの一覧のあと「🗝️ 真のとびらへ」か「🚪 最後のとびらへ」を押す
- 画面を閉じてしまっても、開き直すと本番の画面がそのまま戻る（記録もタイマーもそのまま）

## 5. 終わったあと

- ⑥保存「ファイルに書き出す」で、記録（タイム・順位）を残す
- ⑤印刷「証明書」を印刷すると、チームごとにタイムと順位の入った脱出証明書（脱出できなかったチームは挑戦証明書）になる。後日わたす
- チームシートは担任の先生へ
- 次にまた使うときは ⑥保存「本番の記録を消す」（チームと設定は残る）

## 6. 縦割り活動としてのしかけ

- 謎に「1年生から」「2年生から」「3年生から」のマーク。まずその学年が考え、わからなければみんなで
- 役割：3年生＝リーダー（答えを言わずにヒントで導く）、2年生＝記録係、1年生＝伝令（あいことばを先生に伝える・伝令タイムの主役）。役割カードを1人1枚
- 謎9「3つのかけら」：1年生・2年生・3年生が1枚ずつかけらを持ち、見せずに口で伝え合わないと解けない
- SOSカード：チームで1回だけ、見回りの先生からヒントをもらえる券。使うかどうかはリーダーを中心に相談
- 最後のとびら：脱出できなかったチームもふくめた全員で声をそろえると開き、「先輩からの手紙」が出る
- 特別賞（一番乗り・真・脱出・あきらめない賞・チームワーク賞）と、チームごとの証明書

## 7. 困ったとき

| こまったこと | こうする |
|---|---|
| 学校のパソコンで .html を開けない | 印刷は印刷用PDFから。本番は、開けるパソコン（私物など）をプロジェクターにつなぐ |
| 音が出ない | 画面右上の「音」と、パソコンの音量。④本番「音のテスト」で確かめる |
| 画面を閉じてしまった | 開き直すと本番の画面が戻る（戻らなければ ④本番「続きから」） |
| チームを押しまちがえた | 「記録を取り消す」→ そのチームを押す |
| 時間が足りない | 謎解き中は「＋1分」。解説は一覧だけにして「最後のとびらへ」 |
| 進まないチームが多い | 「ヒントを今出す」。見回りの先生が声をかける（答えは言わない） |
| 別のパソコンで本番をしたい | ⑥保存「ファイルに書き出す」→ USBメモリで運ぶ →「ファイルから読み込む」 |

## 8. 陣取りクイズ（別のゲーム・45分）

クイズに全チームがいっせいに答え、正解したチームがスクリーンの地図の陣地を広げるチーム対抗戦です。

- 用意：陣取りクイズ.html を開いたパソコン＋プロジェクター。答え方は、印刷した回答カード（A・B・C・D・○・×）か、タブレットの回答カード.html か、指の本数
- 準備：②チームでチームの数と名前、③問題で問題を確認（サンプル20問入り。学校オリジナルの問題を混ぜると盛り上がる）、⑤印刷で「進行表とセリフ」「台本（問題と正解）」「回答カード」「チーム札」
- 本番：④本番「はじめる」→ スペースキーで「問題を出す → スタート → 時間切れ → 正解発表 → 正解チームをタップ → 陣地を広げる」をくり返す。最後に結果発表
- 印刷物は 印刷用PDF/陣取りクイズ/ にもあります
